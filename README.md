# Student Learning Management System (LMS)

A simple and interactive **Student Learning Management System** built using **HTML, CSS, and JavaScript**.  
The project simulates a real LMS dashboard with authentication, courses, tasks, and profile management using **Local Storage**.

---

## Features

- **User Authentication**
  - Login & Logout system
  - Password validation
  - Session handling using Local Storage

- **Dashboard**
  - Overview of student activities
  - Announcements section
  - Modern futuristic dark UI

- **Courses Management**
  - View available courses
  - Course data stored per user

- **Tasks Management**
  - Add, view, and manage tasks
  - Tasks saved uniquely for each user

- **Profile Management**
  - Update username
  - Automatically migrates user data (tasks & courses)
  - Success messages instead of alert popups

- **Local Storage Based**
  - No backend required
  - Data persists after refresh

---

## Technologies Used

- HTML5
- CSS3 (Modern / Futuristic Dark UI)
- Vanilla JavaScript
- Browser Local Storage
